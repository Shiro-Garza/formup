# FormUp

Mobile-first web app that helps ROTC cadets plan, log, and track physical training and see how close they are to their fitness assessment target. Leaders get a flight roster with attendance and assessment results.

Team: Kade Garza, Andrew Martin, Ryoma Herd, Izhin Talamantez

Built with SvelteKit.

## Run

```bash
npm install
npm run dev
```

## Styling

All colors, fonts, corner radii, spacing, and layout breakpoints live in `src/lib/theme.css`. Components only use those CSS variables, so editing that one file restyles the whole app.
